Title: Design: complete special fusions and six hero skills

## Nội dung PR

Adds the complete six-pair special fusion table, including a distinct eight-direction lightning+lightning fusion, and six selectable hero skills with activation rules, proposed balance values and timed visual scripts. Defines visible target-color rules for star fusions and a single equipped skill/Nộ system.

Numbers are grounded in main's balance.tres and Orc data; center/edge board-clear examples were checked on a 7×8 board. Proposal only; no game code or balance resources changed. Fusion/skill artwork waits for design approval. The separate art/specials-3d branch supplies the initial bomb/lightning/star set.
